
# Instructor Guide - Smart LMS

Welcome to Smart LMS! This guide will help you create engaging courses, manage students, and track your success.

## Getting Started

1.  **Login**: Access your dashboard at `/login` with your credentials.
2.  **Dashboard**: View your recent courses, revenue stats, and student activity at a glance.

## Creating a Course

1.  Navigate to **Courses** in the sidebar.
2.  Click **New Course**.
3.  **Title**: Enter a descriptive title for your course.
4.  **Description**: Write a detailed description to attract students.
5.  **Thumbnail**: Upload an engaging image (16:9 aspect ratio recommended).
6.  **Price**: Set the price (or leave free).

## Building Curriculum

Smart LMS uses a hierarchical structure: **Chapters (Modules)** -> **Lessons**.

1.  **Add Chapter**: Click "Add Chapter" to create a section (e.g., "Introduction").
2.  **Add Lesson**: Click "+" inside a chapter to add a lesson.
3.  **Lesson Content**:
    - **Video**: Upload a video file or embed from YouTube/Vimeo.
    - **Description**: Add rich text notes.
    - **Attachments**: Add PDFs or downloadable resources.
    - **Access**: Mark as "Free Preview" if desired.

## Assignments & Exams

- **Assignments**: Create practical tasks for students. Set due dates and allowed file types.
- **Exams**: Create quizzes to test knowledge.
    - Add multiple-choice or true/false questions.
    - Set passing scores and time limits.

## Live Classes

Schedule live sessions directly from your course dashboard.
1.  Go to **Live Classes**.
2.  Click **Schedule Class**.
3.  Enter title, date, time, and meeting link (Zoom/Meet).
4.  Students will receive email reminders 1 hour before.

## Managing Students

- View enrolled students in the **Students** tab.
- Track individual progress through lessons and assignments.
- Send announcements via the **Communication** tab.

## Analytics

- Monitor your earnings and enrollment trends in the **Analytics** dashboard.
- View completion rates to identify challenging content.
