# Accessibility + mobile

## Keyboard

- Sidebar: skip link to main content; focus visible on nav items.
- Modals/wizards: trap focus; Escape closes; return focus to trigger.
- Tables: sort controls reachable; row actions labeled.

## Lesson player

- Video: keyboard play/pause; transcript region if available.
- Prefer captions for uploaded video policy (org setting).

## Screen readers

- Page title includes course + lesson name.
- Status announcements for save/errors in live regions.

## Mobile

- Bottom nav for primary student routes.
- Lesson player: sticky bottom controls; minimize chrome on scroll.
- Tables become cards or horizontal scroll with care.

## Contrast

- Glass surfaces must maintain text contrast; use token pairs from `globals.css`.
